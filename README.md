# Biki Haldar – Portfolio (React + Tailwind CSS)

## Run locally
```
npm install
npm run dev
```

## Edit content
Everything (text, projects, skills, links) is in `src/data.js`.
Replace each project's `live` link (currently "#") with the real URL.

## Deploy to GitHub Pages (biki886.github.io)
```
npm run deploy
```
Then in the repo: Settings > Pages > Source = `gh-pages` branch.
